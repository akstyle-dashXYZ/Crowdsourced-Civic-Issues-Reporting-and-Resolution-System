🏛️ CivicConnect — Municipal Complaint Management Platform
A professional, responsive web application for citizens to report municipal issues and track complaints with real-time status updates.

👉 View Live Project : 

📋 Overview
CivicConnect is a smart municipal complaint management system that allows citizens to:

Report civic issues (roads, water, electricity, waste)
Track complaint status in real time
Receive structured communication updates
Access officer dashboard for complaint management
Built using pure HTML, CSS, and Vanilla JavaScript (no frameworks).

✨ Features
👥 Citizen Portal
Submit complaints with category selection
Upload images for issue proof
Location capture support
SMS / WhatsApp / Email notification preferences
Complaint tracking system

📊 Tracking System
Search by Complaint ID or phone number
Real-time status updates
Quick search shortcuts

👮 Officer Dashboard
Secure login system (demo mode included)
Kanban-style complaint management board:
Received
Assigned
In Progress
Resolved
Performance analytics
Communication center (SMS/WhatsApp tracking)
Field mode for on-site updates


📱 Smart Communication
SMS alerts
WhatsApp notifications
Email reports (optional)
Bulk messaging system
